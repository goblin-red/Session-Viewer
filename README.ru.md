# GOBL(in) Session Viewer

[English](README.md) · **Русский**

Позволяет просматривать все сессии ваших терминальных и десктопных агентов.

В одном окне собраны все ваши разговоры с Claude Code, Codex, Grok и OpenCode на этом Mac:
первое сообщение, папка, откуда сессия запущена, размер и дата. Клик по названию показывает, с чего
разговор начался. Для Claude и Codex приложение умеет ещё и добавить терминальную сессию в историю
десктопного приложения, чтобы продолжить её там.
Одно из приложений [GOBL(in)](https://goblin.red).

## Возможности

- Четыре источника: Claude и Codex с импортом, Grok и OpenCode только для просмотра.
- Фильтр по проекту, с числом сессий в каждом.
- Для каждой сессии видны первое сообщение, папка, откуда она запущена (терминал, десктоп, SDK),
  размер, дата и статус.
- Клик по названию сессии показывает первые десять обменов репликами.
- Клик по заголовку столбца сортирует таблицу.
- Служебные запуски (сессии, которые запускали скрипты и другие агенты, субагенты) по умолчанию скрыты;
  их показывает галочка «Служебные запуски».
- Сессии, которые уже есть в десктопе, помечены, и дважды их импортировать нельзя.
- Список подгружается по 50 сессий.
- Два языка интерфейса, английский и русский: по умолчанию английский, переключаются кнопками EN / RU.

## Откуда берутся сессии

| Источник | Где ищутся сессии | Что записывает импорт |
| --- | --- | --- |
| **Claude** | `~/.claude/projects/<проект>/*.jsonl` | маленькую карточку `local_<id>.json` в `~/Library/Application Support/Claude/claude-code-sessions/…` |
| **Codex** | `~/.codex/sessions/**/rollout-*.jsonl` | строку в таблице `threads` базы `~/.codex/state_5.sqlite` |
| **Grok** | `~/.grok/sessions/<проект>/<id>/` | ничего: только просмотр |
| **OpenCode** | `~/.local/share/opencode/opencode.db` | ничего: только просмотр |

Просмотр эти файлы только читает. Импорт не копирует и не меняет сам разговор: он добавляет запись,
которая сообщает десктопному приложению «такая сессия есть, и лежит она вот здесь». После импорта
закройте десктопное приложение (⌘Q) и откройте снова: сессия появится в его истории.

## Установка

Вставьте в Терминал:

```sh
curl -fsSL https://raw.githubusercontent.com/goblin-red/session-viewer/main/install.sh | bash
```

Скрипт скачивает готовую сборку из [Releases](https://github.com/goblin-red/session-viewer/releases/latest),
кладёт её в `/Applications` и открывает. Сборка универсальная: работает и на Apple Silicon, и на Mac с Intel,
инструменты Xcode не нужны. Чтобы обновиться, выполните ту же команду ещё раз.

Скачали архив вручную? Приложение не заверено Apple, поэтому скачанную копию macOS блокирует.
Разблокируйте её один раз:

```sh
xattr -dr com.apple.quarantine "/путь/к/GOBL(in) Session Viewer.app"
```

## Важно

Приложение читает файлы сессий агентов, а импорт пишет во внутреннее хранилище десктопного приложения
Claude и Codex. Эти форматы нигде не описаны и могут измениться с любым обновлением, тогда источник
или импорт перестанет работать. Это личный инструмент, используйте его на свой риск.

## Что нужно

- macOS 10.15 или новее
- Хотя бы один из агентов: Claude Code, Codex, Grok, OpenCode

## Сборка из исходников

Нужны Command Line Tools (`xcode-select --install`).

```sh
git clone https://github.com/goblin-red/session-viewer.git
cd session-viewer

./build_app.sh
open "build/GOBL(in) Session Viewer.app"
```
