# Changelog

## 2026-10-02
- Приложение переименовано в GOBL(in) Session Viewer: оно показывает все сессии терминальных и десктопных агентов, импорт остался дополнительной возможностью для Claude и Codex. Собирается в `build/GOBL(in) Session Viewer.app`, исполняемый файл `SessionViewer`, bundle id `local.goblin.session-viewer`.
- Интерфейс стал двуязычным: английский по умолчанию, русский по кнопкам EN / RU вверху окна; выбор запоминается.
- Добавлены `install.sh` (установка готовой сборки из GitHub Releases одной командой) и `package.sh` (упаковка сборки для Releases).
- В таблицу сессий добавлен столбец «Размер» — размер файла сессии.
- Окно стало шире (1060 вместо 760), промежутки между столбцами уменьшены, столбцы подгоняются под ширину окна: «Статус» больше не уезжает за край.
- Сборка стала универсальной: arm64 (macOS 11+) и x86_64 (macOS 10.15+) в одном бинарнике; раньше приложение собиралось под версию системы на машине сборки.
- Добавлены README на двух языках, LICENSE, VERSION и .gitignore.
- Добавлены логотип Goblin в окне (`logo.svg`) и иконка приложения (`AppIcon.icns`).
- Codex: исправлен разбор сессий. Новые версии Codex (0.15x+) пишут реплики в записях `event_msg` / `item_completed` (`UserMessage`, `AgentMessage`), а не в `user_message` / `agent_message`, поэтому в списке было «(без текста)», а «Подробнее» оставалось пустым. Теперь понимаются оба формата.
- Codex: служебные запуски (`codex exec` из скриптов и других агентов, субагенты) скрыты по умолчанию; их показывает галочка «Служебные запуски», число скрытых видно в строке состояния.
- Добавлен столбец «Откуда»: Терминал, Десктоп, SDK, Автозапуск, Субагент. Для Claude берётся из поля `entrypoint` записей сессии (`cli`, `claude-desktop`, `sdk-*`), для Codex — из `originator` в `session_meta`.
- Кнопка «Подробнее» убрана: начало разговора открывается кликом по названию сессии.
- Добавлена сортировка таблицы по клику на заголовок столбца: первое сообщение, папка, откуда, размер, дата, статус.
- Добавлены источники Grok и OpenCode в режиме «только просмотр»: список сессий, размер, дата, начало разговора по клику; кнопка импорта для них отключена. Grok читается из `~/.grok/sessions/<проект>/<id>/` (`summary.json`, `chat_history.jsonl`), OpenCode — из таблиц `session`, `message`, `part` базы `~/.local/share/opencode/opencode.db`. Служебные сессии (Grok: `session_kind` headless/subagent; OpenCode: с `parent_id`) скрыты той же галочкой.
- Сессия больше не пропадает из списка, а «Подробнее» не выдаёт ошибку, если чтение начала файла обрывается посреди символа.

## 2026-06-13
- Добавлена пагинация в таблицу сессий: грузятся порциями по 50 (кнопка «Показать ещё N», счётчик показано/всего); сброс к первой странице при смене проекта.
- Добавлен выбор источника (Claude/Codex, по умолчанию Claude). Codex: скан `~/.codex/sessions/**/rollout-*.jsonl`, импорт = INSERT в таблицу `threads` базы `~/.codex/state_5.sqlite` (через libsqlite3), «уже импортированные» = id есть в threads. Отдельный парсер rollout (session_meta/turn_context/event_msg) и codex-вариант «Подробнее». В build_app.sh добавлен `-lsqlite3`.
